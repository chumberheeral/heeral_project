Checking Figma Files for Color and Accessibility Problems
This tool would look at a Figma design file and check it for color problems — mainly text that's too light against its background, or two colors that look different to me but would look almost the same to someone who's color blind. As a UX designer I pick colors that look great on my own screen, but I don't always catch that a button and its background would blend together for someone with color blindness. The tool would connect to Figma through their API, pull the colors used in a file, and run them through the standard contrast rules. It would also show what the design looks like to someone with different types of color blindness, so I can actually see the problem instead of just being told about it.
Example: I finish a set of app screens in Figma, paste the file link and my access token into the tool, and a minute later it tells me my "Skip" button text is too light to pass, along with a slightly darker shade that still fits my color scheme.
Who it's for and what it solves
Mainly designers like me, checking our own files before handoff. Developers benefit too, since they won't catch these issues later during a code review, and the real winners are end users with low vision or color blindness. Color problems like this get missed constantly because checking every pairing by hand is tedious — this just automates it.
How it works and what it would look like
Paste in a Figma link, get back a report, fix the color, run it again if you want. Probably a small Flask web page — paste a link and token, get a results page back. Data comes straight from Figma's free API, so no dataset hunting needed, and the actual checking (contrast math, color blindness simulation) runs locally using known formulas.
Hardest part and what I can do myself
Figma files are structured in a pretty nested way, so pulling out exactly which color is showing on top for a given piece of text could be tricky, and so could getting the color blindness simulation right. I use Figma every day and know the contrast rules from real design work, so testing this on real files won't be a problem — I'd want help with the API and the simulation math.
